## 2. สรุปผลการประเมินด้าน Non-Functional Requirements

- **ด้านประสิทธิภาพ (Performance):**
  - หน้าแสดงผล Portfolio สาธารณะ (`/r/[slug]`) โหลดข้อมูลเสร็จสิ้นในเวลาต่ำกว่า 0.8 วินาที
  - การบันทึกข้อมูล (Save) ใน Editor ใช้เวลาตอบสนองเฉลี่ยต่ำกว่า 300 มิลลิวินาที
- **ด้านความปลอดภัย (Security):**
  - รหัสผ่านทุกบัญชีจัดเก็บด้วยการแฮชแบบ `scrypt` พร้อม Unique Salt ป้องกัน Rainbow Table Attack
  - Session Cookie ถูกลงนามด้วย HMAC-SHA256 Secret ป้องกันการปลอมแปลง Token
  - เส้นทาง API ได้รับการคุ้มครองด้วยการตรวจสอบ Role ทุกครั้งที่มีการร้องขอ (Role Guards)

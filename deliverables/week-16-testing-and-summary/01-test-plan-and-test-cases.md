# 🧪 แผนการทดสอบและกรณีทดสอบระบบ (Test Plan & Test Cases)

**โครงการ:** ระบบ Portfolio ออนไลน์สำหรับนักศึกษาวิศวกรรมคอมพิวเตอร์ (PFS)  
**เอกสารประกอบ:** สัปดาห์ที่ 16 (System Testing & Semester 1 Summary)  
**ระดับการทดสอบ:** Functional Testing, Integration Testing, Security & Permission Testing

---

## 1. ขอบเขตและกลยุทธ์การทดสอบ (Testing Scope & Strategy)

การทดสอบในภาคเรียนที่ 1 มุ่งเน้นการตรวจสอบความถูกต้องของการทำงานตามข้อกำหนด (Functional Requirements FR-001 ถึง FR-032) และการรักษาความปลอดภัยของระบบ โดยแบ่งเป็น 6 โมดูลหลัก:
1. **Module 1: ยืนยันตัวตนและการจัดการสิทธิ์ (Authentication & Authorization)**
2. **Module 2: การจัดการข้อมูลส่วนตัวและบัญชีผู้ใช้ (User Profile & Account)**
3. **Module 3: ระบบสร้างและปรับแต่ง Portfolio (Studio 12-Column Grid Editor)**
4. **Module 4: การเผยแพร่ผลงานและการเข้าชมสาธารณะ (Publishing & Public Portfolio)**
5. **Module 5: ระบบบริหารจัดการนักศึกษาของผู้ดูแลระบบ (Admin Student Management)**
6. **Module 6: ความปลอดภัยและการป้องกันข้อผิดพลาด (Security & Exception Handling)**

### สภาพแวดล้อมการทดสอบ (Test Environment)
- **Runtime:** Node.js v20+ / Next.js 16 (App Router)
- **Database:** MongoDB 7.0 (Docker Container / Local Replica)
- **Browsers:** Google Chrome, Microsoft Edge, Safari, Mozilla Firefox
- **Test Accounts:**
  - Student: `student@pfs.local` / `Student@1234` (รหัส `64010123`)
  - Admin: `admin@pfs.local` / `Admin@1234`

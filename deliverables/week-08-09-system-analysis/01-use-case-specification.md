# 📋 Use Case Specification (ข้อกำหนดการใช้งานระบบ)

**โครงการ:** ระบบ Portfolio ออนไลน์สำหรับนักศึกษาวิศวกรรมคอมพิวเตอร์ (PFS)  
**เอกสารประกอบ:** สัปดาห์ที่ 8-9 (System Analysis & Design)

---

## 1. ผังบทบาทผู้ใช้งาน (Actors)

| Actor | รายละเอียดและขอบเขตสิทธิ์ |
|---|---|
| **Student (นักศึกษา)** | ผู้ใช้งานหลักที่ได้รับการลงทะเบียนจากระบบ สามารถเข้าสู่ระบบ จัดการข้อมูลส่วนตัว เลือกเทมเพลต ออกแบบและจัดวางองค์ประกอบ Portfolio/Resume ผ่าน 12-Column Grid บันทึกแบบร่าง และสั่งเผยแพร่ (Publish/Unpublish) สู่สาธารณะ |
| **Admin (ผู้ดูแลระบบ)** | ผู้ดูแลระบบฝ่ายทะเบียน/ภาควิชา สามารถเข้าสู่ระบบ ดูรายงานสถิติ จัดการบัญชีนักศึกษา (เพิ่ม, แก้ไขข้อมูล, ปิด/เปิดใช้งานบัญชี, รีเซ็ตรหัสผ่าน, ลบบัญชี) และตรวจสอบเนื้อหา Portfolio ของนักศึกษาทุกคน |
| **Public Visitor (ผู้เข้าชมทั่วไป)** | บุคคลภายนอก เช่น นายจ้าง, อาจารย์ที่ปรึกษา หรือบุคคลทั่วไป ที่เข้าชมหน้า Portfolio สาธารณะผ่านลิงก์เฉพาะ (`/r/[slug]`) โดยไม่ต้องเข้าสู่ระบบ |

## 3. รายละเอียด Use Case สำคัญ (Use Case Descriptions)

### UC-01: เข้าสู่ระบบ (Login)
- **Actor:** Student, Admin
- **Precondition:** ผู้ใช้มีบัญชีที่สถานะเปิดใช้งาน (`active`) ในระบบ
- **Main Flow:**
  1. ผู้ใช้เข้าหน้าเว็บ `/login`
  2. กรอกอีเมลหรือรหัสนักศึกษา และรหัสผ่าน
  3. กดปุ่ม "เข้าสู่ระบบ"
  4. ระบบตรวจสอบความถูกต้องของรหัสผ่านที่เข้ารหัสด้วย scrypt และสถานะบัญชี
  5. ระบบสร้าง Cookie Session Token ที่ลงนามความปลอดภัย (HMAC-SHA256)
  6. หากเป็น Role `student` ระบบพาไปหน้า `/student` หากเป็น `admin` ระบบพาไปหน้า `/admin`
- **Alternative Flow:**
  - 4a. กรอกรหัสผ่านผิด: ระบบแจ้งเตือน "อีเมล รหัสนักศึกษา หรือรหัสผ่านไม่ถูกต้อง"
  - 4b. บัญชีถูกระงับ (`inactive`): ระบบแจ้งเตือน "บัญชีนี้ถูกปิดใช้งาน กรุณาติดต่อผู้ดูแลระบบ"

---

### UC-07: ปรับแต่งและจัดวางบล็อกเนื้อหา (Edit Grid Elements)
- **Actor:** Student
- **Precondition:** เข้าสู่ระบบในสถานะ Student และอยู่ในหน้า `/student/editor`
- **Main Flow:**
  1. นักศึกษาเลือกเพิ่ม Element จาก Asset Library ด้านซ้าย (เช่น Profile, About, Skills, Projects, Experience)
  2. ระบบเพิ่มบล็อกลงบน 12-Column Grid Canvas
  3. นักศึกษาคลิกเลือกการ์ดเพื่อเปิดพาเนลด้านขวา
  4. ปรับเปลี่ยนตำแหน่ง Grid (Col Start/End, Row Start/End) หรือเลือก Quick Size
  5. แก้ไขเนื้อหา รายการย่อย รูปภาพ และรูปแบบแสดงผล (เช่น Skill Progress Bars, Glowing Pills, Timeline)
  6. นักศึกษาสามารถคลิกลบหรือซ่อนการ์ดผ่าน Floating Action Toolbar
- **Postcondition:** โครงสร้าง Layout อัปเดตแบบเรียลไทม์บน Canvas

---

### UC-10: เผยแพร่ผลงานสู่สาธารณะ (Publish Portfolio)
- **Actor:** Student
- **Precondition:** นักศึกษาออกแบบและบันทึก Portfolio ไว้เรียบร้อยแล้ว
- **Main Flow:**
  1. นักศึกษากดปุ่ม "Publish" บน Command Toolbar
  2. ระบบตรวจสอบความถูกต้องของ Slug (ไม่ซ้ำกับผู้อื่น)
  3. ระบบเปลี่ยนสถานะในฐานข้อมูลเป็น `published` และบันทึกเวลา `publishedAt`
  4. ระบบสร้างลิงก์สาธารณะ เช่น `/r/my-portfolio`
  5. ระบบแสดงปุ่ม "แชร์ Portfolio" และปุ่มเปิดดูหน้าจริง
- **Postcondition:** บุคคลภายนอกสามารถเปิดดูหน้า Portfolio ผ่านลิงก์ได้ทันที

---

### UC-13 to UC-17: การจัดการบัญชีนักศึกษาโดยผู้ดูแลระบบ (Admin Account Management)
- **Actor:** Admin
- **Precondition:** เข้าสู่ระบบในสถานะ Admin และเปิดหน้า `/admin`
- **Main Flow:**
  1. ผู้ดูแลระบบสามารถค้นหานักศึกษาจากชื่อ, รหัสนักศึกษา หรืออีเมล
  2. **เพิ่มนักศึกษา:** กดปุ่ม "เพิ่มนักศึกษา" กรอกรหัส ชื่อ นามสกุล อีเมล สาขา ชั้นปี และกดบันทึก
  3. **แก้ไขข้อมูล:** กดปุ่มแก้ไขที่แถวของนักศึกษา ปรับปรุงข้อมูล และกดยืนยัน
  4. **ระงับ/เปิดใช้:** คลิกปุ่มสลับสถานะบัญชี (`active` <-> `inactive`)
  5. **รีเซ็ตรหัสผ่าน:** คลิกปุ่ม Reset Password เพื่อตั้งรหัสผ่านใหม่ให้นักศึกษา
  6. **ลบบัญชี:** คลิกปุ่มลบ พร้อมยืนยันการลบข้อมูล
- **Postcondition:** ฐานข้อมูล `users` อัปเดตทันที และนักศึกษาได้รับผลตามสิทธิ์ใหม่

---

### UC-19: ตรวจสอบและดูตัวอย่าง Portfolio ของนักศึกษา (Review Student Portfolio)
- **Actor:** Admin
- **Precondition:** เข้าสู่ระบบในสถานะ Admin
- **Main Flow:**
  1. Admin ดูรายการนักศึกษาในตาราง
  2. ในคอลัมน์ Portfolio ระบบแสดงสถานะ (Published / Draft / ยังไม่สร้าง)
  3. Admin สามารถคลิกปุ่ม **"เปิดดู"** เพื่อเปิดดูหน้า Portfolio สาธารณะ (หาก Published) หรือคลิก **"ตรวจแบบร่าง"** เพื่อดูเนื้อหาของนักศึกษาที่กำลังจัดทำอยู่ (Draft) ได้ทันที
- **Postcondition:** Admin สามารถติดตามความคืบหน้าการส่งงานของนักศึกษาได้ครบทุกคน
